## 实验性等级使用边界

玩家/帕鲁详情中的“实验性 MOD 等级”默认折叠。备份完整世界并确认 MOD 规则后，勾选确认，输入目标等级和 MOD 对应的**累计经验**，应用后仍按现有保存流程保存。每次成功操作后确认与经验输入会清空；切换对象/会话也会重置。

- 普通界面保持 80、原有超限选项保持 100；一键最大化不启用实验模式。
- `Level` 的 ByteProperty 可存储 0–255，本功能接受有效等级 1–255。255 只是序列化边界，绝不代表游戏支持 255 或无限等级，也没有改成 IntProperty。
- 编辑器只有 1–100 的经验规则，不推测 MOD 曲线。大于 100 缺少经验会返回 `MOD_EXPERIENCE_REQUIRED`；后端拒绝布尔、非整数、负数和溢出经验。
- 界面只接受 JavaScript 可精确表示的整数，最大累计经验为 `9007199254740991`；后端上限仍为有符号 64 位整数。没有对大整数做静默舍入。
- 已存在但不符合支持结构的 Level 属性会拒绝修改。玩家降级仍受到原有可用属性点约束。
- Global Palbox 目标世界也必须有兼容的 MOD。客户端、服务器、目标世界的等级/经验规则都要一致；这次没有安装任何 MOD。

## 安全与格式保真

远征的无关对象隔离仅适用于**外层结构完整、原始 ByteProperty 边界可信**的情况。外层损坏、远征载荷损坏、重复 ID 或无法验证成员信息时，索引不会授权解锁。无法识别的布局保持原始字节，不通过吞掉异常或猜测下一条边界来继续写远征字段。可识别的旧版非空任务布局可往返保存，但不能用它推断完整成员引用；歧义或损坏布局安全拒绝索引。

Steam/WGS 沿用现有存储适配器、会话/修订检查、备份和保存事务。迁移到 XGP/WGS 目标的现有限制仍保留，未把导出 Steam 副本算作 WGS 写回。
