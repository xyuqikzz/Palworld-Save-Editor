# Web API

Flask 路由层负责认证、请求解析、错误转换和响应序列化。存档读取、命令验证、变更记录和写入逻辑应放在 `application/`、`domain/` 与 `core/`，不要继续把 GVAS 字段路径堆进路由函数。

## 路由分组

- `auth.py`：登录和令牌检查。
- `save.py`：会话生命周期、查询、待保存变更、保存、路径与版本信息。
- `player.py`：玩家命令、背包、物品属性和物品栏布局。
- `pal.py`：帕鲁字段命令、结构性新增/复制/删除及其预览。
- `batch.py`：批量命令的影响预览和原子执行。
- `preset.py`：预设导出、预览和应用。

## 约束

- 除明确公开的无认证端点外，路由必须使用 JWT 认证。
- 修改请求必须携带当前会话和 revision；过期 revision 不得静默覆盖新状态。
- 路由先解析输入，再调用应用服务；不要直接修改原始存档字典。
- 危险或结构性操作必须先提供预览，并返回受影响对象和阻止原因。
- 统一使用 `reply(...)` 响应封装，并把领域错误映射为稳定的错误码和消息。
- 只有 `/save` 可以把待处理变更写入磁盘；写入必须经过 `SaveWriter`。

API 集成测试位于 [`tests/integration/api`](../../../tests/integration/api)。
